## 📌 Overview:--
The **Arduino Uno Simulator** is a browser-based interactive platform that allows users to design, wire, and simulate Arduino circuits without physical hardware. It is specifically built for beginners and educators to master Arduino fundamentals through real-time visual interaction.

---

## 🚀 Key Features:-
* **🧩 Drag-and-Drop Interface:** Intuitive workspace for placing components.
* **🔌 Smart Wiring:** Supports both Auto-wiring and Manual wiring modes.
* **⚙️ Pin Configuration:** Full control over Digital pins 2–13 via a dedicated panel.
* **▶️ Real-Time Simulation:** Start/Stop logic to observe circuit behavior instantly.
* **🧾 Code Generation:** Automatically generates Arduino (C++) code based on your visual design.
* **📟 Serial Monitor:** Built-in monitor (9600 baud) for debugging and data output.

## 🛠️ Components Supported:-
| Component | Type | Function |
| :--- | :--- | :--- |
| **Arduino Uno** | Microcontroller | ATmega328P based logic core |
| **LED** | Output | Visualizes digital HIGH/LOW states |
| **Push Button** | Input | Interacts with pull-up/down logic |

## 🧪 How It Works:-
1. **Design:** Drag the Arduino Uno and components onto the canvas.
2. **Connect:** Use the wiring tools to link components to specific digital pins.
3. **Configure:** Use the Pin Configuration Panel to set logic parameters.
4. **Code:** The **Code Panel** updates dynamically as you build.
5. **Run:** Click **Start Simulation** to interact with your virtual hardware.

## 🧑‍💻 Tech Stack Used:-
* **Frontend:** HTML5 (Canvas rendering) & CSS3 (Modern UI)
* **Logic:** Vanilla JavaScript (State management & simulation engine)
* **Embedded Logic:** Arduino C/C++ (Simulation of microcontroller behavior)
